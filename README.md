## 📲 Installing on Android
1. Download `DigitolPrint.apk` on your phone.
2. Tap the file. If asked, allow **Install unknown apps** for your browser.
3. Tap **Install**.

## 💻 Installing on Windows
1. Download and run `DigitolPrint-Setup.exe`.
2. If Windows SmartScreen appears, click **More info → Run anyway**.
3. Follow the setup wizard. No admin rights needed.

## 🔒 Privacy
Print files travel directly from the customer to the shop's PC through an encrypted tunnel. They are never stored on any cloud server.
